## 信用原始規則：尚未能確認

證據來自現有交接說明 `docs/QUESTIONS_TO_RETURN.md`、設定檔及實作；沒有找到原作者可重現的策略程式與配對輸入，因此不能宣稱已重現截圖。

現有工程候選定義：令同一美國交易日還原權息收盤價比值為 `R[t] = HYG[t] / SHY[t]`，`I[t] = 1 - count(R[j] <= R[t], j=t-188..t) / 189`。包含當日、同值用小於等於、未先四捨五入；因此值域為 0 到 188/189。189 指有效配對觀測數，並不是 189 個日曆日。現有函式過濾缺值後計數，尚未用美國完整交易日曆驗證連續性；在正式啟用前必須釐清缺漏是否使窗口失效。

| 項目 | 可確認的工程行為 | 尚待原作者確認 |
| --- | --- | --- |
| 189 日百分位 | 含當日的上述反向排名；不足時無指標 | 是否同式、同值排名、是否平滑、是否固定連續交易日 |
| 0.30 | 目前正式門檻為 null | 是否 `I < .30` 持有、`.30` 歸哪側 |
| ±0.05 | 以 .30 為中心會是 .25/.35 | 黃燈區、遲滯切換或僅視覺提示；截圖另有 .28/.32 |
| 延遲一天 | 候選持倉用前一筆完整窗口的指標；最早需190筆 | 美國交易日、下單／成交時點、進出場門檻與燈號是否相同 |

0.2540 約為 48/189，0.2804 約為 53/189，與候選百分位格點相容，但不是公式已獲證實。若採截圖文字的單一 .30 門檻，兩值均應 GREEN。若採 .25/.35 黃燈區，.2540 應位於區內。若採遲滯，過去 RED 確實可能在 .2540 保持 RED；但交接記錄顯示 5/15 的 .2804 為 GREEN、5/18 的 .2540 為 RED，假設相鄰有效交易日、同一指標且無其他條件，單純遲滯不能解釋此轉換。將前一日 .2804 用於 .30 持倉判斷也不能解釋「不持有」。5D avg .1619 亦低於上述門檻。

可能原因包括不同資料版本／更新時間、燈號與持倉欄位使用不同序列、其他未揭露條件、人工覆寫或顯示錯誤；目前均為待驗證假設。需要原作者提供兩日輸入、前一狀態、判斷函式、至少200筆配對價格及資料權利證據。未將任何假設寫成正式規則。

## 免費歷史回補可行性

| 來源 | 已確認 | 限制與本階段結論 |
| --- | --- | --- |
| TWSE 個股日成交資訊，開放資料集11549 | 免費、政府資料開放授權條款第1版；連到 STOCK_DAY_ALL CSV及官方 OpenAPI | 可在授權條件下保存、計算、公開並顯名。官方 OpenAPI `/exchangeReport/STOCK_DAY_ALL` 的 GET 沒有歷史日期參數；不能假設加 date 就能回補 |
| TWSE 個股日成交歷史查詢 | 官網提供自2010-01-04起的查詢與 CSV | 技術上時間深度足夠；網站歷史查詢與批次取得方式是否在開放授權範圍，需來源對應或提供機關確認，未啟動爬取 |
| TPEx 收盤行情，開放資料集11371 | 免費、相同開放授權；資料含股票、ETF、ETN、權證等 | 不能把全部證券當普通股母體。官網另有2007年起的歷史查詢；應核對與資料集欄位／交易口徑、日期格式及授權涵蓋，再回補 |

本次直接讀取兩個官方 swagger 定義檢視路徑與參數，未抓取批次歷史行情。TPEx `/tpex_mainboard_quotes` 與 `/tpex_mainboard_daily_close_quotes` 的 GET 也未宣告歷史日期參數，不能宣稱已提供任意日期免費 API。網站可查詢／CSV可下載不等於允許自動化大量擷取；兩交易所條款都限制未經同意的自動下載。已開放資料可依相應授權使用，不能將例外擴張到全部網站資料。

工程上至少需要最近240個**預期交易日**才可算 MA240；240日突破另需241日。MA20／60／120同理需完整20／60／120日窗口。目前均線介面仍顯示原有20／60／120，MA240未新增交易條件；底層 MA 函式已測試239/240邊界。建議授權範圍確認後先採約300個交易日緩衝，再以有效完整窗口決定可用，不能用固定365日或有值筆數冒充。

後續回補驗收條件：

1. 母體：先保留 TWSE 普通股範圍；TPEx 使用獨立官方公司／證券類型名單。保存納入、上市、下市、轉板日期與市場識別，不只靠四位數代號。現在的最新公司名單含存活者偏誤，不能直接做歷史績效回測。
2. 權息：官網 OHLC 是成交價，不是已驗證的還原總報酬價。保留 `unadjusted`。除權息參考價與含息總報酬不同，另需現金／股票股利、分割、減資、現增與生效日及版本；TWSE 除權息結果表也明示有排除項目。不能用單一參考價比率宣稱完成所有權息調整。價格基礎變更需另行決定。
3. 交易日：以各市場官方開休市與臨時停市公告為準，保存台北交易日與抓取時間。上市前不補造；停牌、無成交、抓取失敗分開標記。休市不當資料缺漏，抓取失敗不當休市。
4. 缺漏：缺值保留 null，不補零、不向前填價、不壓縮掉交易日；有缺值的窗口不可用。回補需按日期＋市場＋代號去重、核對要求日與回傳日、校驗單位／異常價格、附來源摘要及授權資料。
5. 安全與成本：只用已確認的官方免費介面；先少量人工抽查，再單工、快取、可續傳、有限重試。遇403/429停止或依 Retry-After，不能換IP繞過。未查到統一可承諾的官方請求額度，不自行宣稱任何速率獲准。不採購付費歷史商品。

**可行性判斷：** 免費累積已開放的每日盤後資料可行；立即合法批量回補240日仍有歷史端點與授權對應待確認，不應宣稱已取得完整回補資格。選擇等待官方書面／資料集證據，或提供有使用及公開權利的歷史檔。這次沒有產生歷史資料下載成本，也未啟用每日累積排程。

## 驗證與安全範圍

本地：26個 Python 測試（其中一項含22組共用契約案例）、47個 Node 測試、Vite 正式建置通過。新增瀏覽器案例覆蓋「缺日曆顯示待核對」及「拒絕以JSON自行核准信用規則」。本地 Chromium 執行器缺少瀏覽器 binary，11個瀏覽器測試在啟動前被環境阻擋；以 GitHub-hosted CI 安裝 Chromium 後的實際結果驗收，結果連結記錄於 PR #1。

安全檢查涵蓋本次所有待提交文字檔與既有追蹤檔路徑：常見憑證格式、私鑰、敏感檔案、正式行情內容與禁用設定。無新增行情、T86或信用價格序列；共用測試案例僅含合成值／既有核准 fixture。未更改價格來源授權設定、信用門檻、main、其他Repository或付費配置。契約驗證與SHA欄位只能檢查結構及追溯欄位，不能證明任意使用者上傳的資料真實性。此次不是完整滲透測試或所有相依套件弱點稽核。
