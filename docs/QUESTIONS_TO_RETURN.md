## 先回答 Q1–Q4：信用燈號目前的阻礙

**Q1｜0.2540 為什麼是 RED？**

2026-05-18 截圖的信用指標是 0.2540，卻顯示 RED；表格寫 GREEN <0.30、RED ≥0.30。2026-05-15 的 0.2804 又顯示 GREEN。請提供這兩天的輸入資料、前一日狀態、判定程式，以及觸發 RED 的具體條件。是否有記憶前一日狀態、升降速度、另一個指標或人工覆寫？若是原站顯示錯誤，也請明確指出。

**Q2｜真正的綠／黃／紅門檻及邊界是哪一組？**

截圖表格中心是 0.30；圖例標出 0.28／0.32；文字又寫 ±0.05（數學上會是 0.25／0.35）。請回覆實際 green、yellow、red 條件，等於門檻歸哪一側，以及升／降時是否用不同切換門檻。黃燈是獨立狀態、緩衝區，還是只有視覺提示？

**Q3｜燈號到底用原始指標、5 日平均，還是交易部位狀態？**

截圖有「指標 0.2540」「5D avg 0.1619」「持續 1 天」「切換日期」與「不持有／低槓桿」。請提供各欄位的公式及依賴關係：燈號用哪個值、何時更新、是否延遲一個美國交易日、進出場是否另用 0.30？請提供完整狀態機或原始函式。

**Q4｜HYG／SHY 指標如何重現？**

是否使用 HYG、SHY 的還原權息收盤價？189 個交易日是否含當日？百分位遇到相同值如何排名？是否先四捨五入、平滑、重新取樣或改用其他期間？請提供截至 2026-05-18 至少 200 筆同日配對的 HYG／SHY／SPY 原始價、來源日期和計算輸出，並附可使用／公開轉載的授權說明。請勿提供任何 API Key、帳密或券商憑證。

## 其他尚未能確認的原站算法與資料

**Q6｜AE 體制偵測的原始定義？**

**Q7｜歷史行情與還原方式可以提供嗎？**

交接包沒有個股歷史快照。工程版已開始累積官方盤後資料，但目前只有 1 個價量交易日，MA20／60／120、N 日突破正在暖機。請提供可合法免費使用的歷史資料、交易日、除權息／分割因子與調整公式。原站的均線與突破是使用未還原價、還原價格，還是含息總報酬價？請附授權，避免從不完整樣本推算。

**Q8｜原站金融資料的公開轉載授權與使用範圍？**

請逐一提供 HYG／SHY／SPY、S&P 500 成分／熱力圖、券商分點、盤中量能、盤前國際市場、台股歷史與 T86 個股法人資料的實際來源、公開轉載許可、時間戳及更新頻率。能免費讀取 API 不等於可以公開轉載。TWSE OpenAPI 與 TAIFEX 官方開放資料已核對；T86 的精確開放授權對應仍需補證據。不接受未經同意的付費替代來源。

**Q9｜原站的母體與期貨口徑？**

原站是否包含上市、上櫃、ETF、停牌或下市股票？熱力圖用市值、成交額還是等權？目前工程版使用可核實公司名單篩選 TWSE 普通股，排除 ETF／權證；沒有宣稱上市櫃全市場。期貨現在是 TAIFEX 官方「臺股期貨 TX」各到期月份合計淨未平倉；原站是否另外納入 MTX、TMF、夜盤或換算大台等值？若不同，請提供原公式。

**Q10｜截圖的回測數字如何驗算？**

請提供原始回測程式／交易紀錄、日期區間、資料版本、訊號與成交時點、長空規則、槓桿、交易成本、股息、年化算法及最大回撤的權益序列。截圖的 CAGR／Sharpe／MDD 與 CTA 勝率不能只憑圖片複製到工程版，目前沒有把它們當成已驗證績效。
