- https://data.gov.tw/dataset/11549
- https://openapi.twse.com.tw/v1/exchangeReport/STOCK_DAY_ALL

另已確認資料集11543「終止上市公司」列有政府資料開放授權。網站亦可查詢「個股日成交資訊」歷史月份及「暫停交易證券」，但我們不將手動查詢或CSV按鈕視為已允許自動歷史批次下載，因此尚未執行歷史批量取得。

煩請就下列事項提供明確資料集、端點、條款或書面說明：

1. 是否有免費且獲准自動取得之上市普通股每日開盤、最高、最低、收盤、成交股數（OHLCV）歷史檔或API？需求為最近約300個交易日、全部符合資格的上市普通股（目前約1,085檔），且希望包含期間內已下市或轉板股票，以避免存活者偏差。是否包含創新板、KY、變更交易／分盤交易股票？非普通股將排除。
2. 資料集11549之授權是否僅涵蓋直接提供的最新快照？是否也涵蓋網站個股月份查詢的歷史資料與其自動化取得介面？如可使用，請提供確切路徑、合法參數、涵蓋期間、請求頻率、並行數、快取及重試限制。
3. 對指定歷史資料，是否允許以下不同用途？請分別確認：私人研究環境保存與計算；公開GitHub存放原始或欄位投影後逐日資料及Git版本歷史；公開網站顯示逐股價格、歷史圖、均線、廣度及衍生訊號；提供可下載JSON。GitHub可能被他人下載或fork，歷史版本會持續存在。若只能公布衍生統計，請具體說明逐股衍生值、延遲時間及資料保存限制。
4. 依政府資料開放授權條款已開放的資料，是否無須另行書面核准即可依指定方式保存、加工、公開再散布？請提供適用的顯名聲明、版本與端點對應，並說明與網站使用條款、交易資訊商品授權的界線。
5. 是否有免費、完整的跨年度交易日曆（含颱風等臨時休市）、IPO、上市／上櫃轉板、暫停／恢復交易與終止上市資料？請確認資料集11543及暫停交易資料涵蓋起訖與修訂機制，並提供穩定股票識別及生效日期定義。
6. 是否有可合法取得且足以驗證的股息、配股、現金增資、分割、減資等公司行動檔，或價格還原／總報酬調整因子？請說明公式、再投資假設、生效日、精度、修正版本及再散布權限。我們明確區分除權息參考價、價格還原與總報酬還原，不會自行宣稱等同。
7. 如完整需求沒有免費方案，請直接告知免費授權所能涵蓋的範圍即可，無須建立付費帳號或訂單。

若確認可用，預計先以2–3檔普通股、少量日期（包含一個公司行動或停復牌事件）做人工與程式對帳；通過並另行核准後才提出一次性300日回補方案。後續擬每個交易日盤後更新一次，優先採全市場檔、單工、快取及節流；實際頻率依貴所規範。現階段尚未啟用每日排程。
